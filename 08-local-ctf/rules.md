# CTF Rules of Engagement

1. **Authorization & Scope:** Only test resources explicitly designated within the local server environment (`127.0.0.1` or designated local subnet).
2. **Flag Format:** Every discovered flag adheres to `FLAG{<unique_string>}`.
3. **Evidence Requirement:** Every flag submission must include:
   * How it was found
   * Commands and tools used
   * Evidence / screenshot / output trace
   * The underlying vulnerability or misconfiguration
4. **No Destructive Actions:** Do not alter, delete, or overwrite challenge binaries or server state.
