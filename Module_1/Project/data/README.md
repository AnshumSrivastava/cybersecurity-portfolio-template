# Data and Evidence

These files are sanitized, scoped training evidence. They support the completed project but do not represent a live network.

| File | Type | Use |
|---|---|---|
| `lab-web-01-nmap.xml` | Synthetic Nmap XML | Repeatable parser/report exercise |
| `nmap-sanitized-example.txt` | Human-readable scan excerpt | Example evidence presentation |
| `capture-summary.csv` | Derived packet-observation data | Completed Wireshark analysis exercise |
| `wireshark-observations-completed.md` | Completed analysis record | Fact/interpretation/limitation example |
| `wireshark-notes.md` | Blank observation worksheet | Learner capture analysis |
| `public-dns-capture-analysis.md` | Derived analysis of a public Wireshark sample | Real offline-PCAP learning activity; raw PCAP intentionally excluded |

For data retention, sanitization, and chain-of-evidence rules, see [../instructions/data-provenance.md](../instructions/data-provenance.md).
