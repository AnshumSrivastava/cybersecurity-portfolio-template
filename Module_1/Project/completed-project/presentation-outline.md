# Five-Minute Project Presentation

1. **Objective and authorization (30 seconds):** assessment goal, approved lab only, and exclusions.
2. **Topology and assets (45 seconds):** show `topology.mmd`; identify the edge, workstation, web service, resolver, and trust boundaries.
3. **Evidence and method (60 seconds):** limited three-port Nmap observation; offline Wireshark filters; explain why no raw PCAP is submitted.
4. **Results (75 seconds):** ports 80/443 open, 22 closed; DNS/TCP/TLS observations; say exactly what remains unproven.
5. **Risk and recommendations (60 seconds):** HTTP validation, allowlist matrix, patch/certificate governance, ownership.
6. **Limitations and next step (30 seconds):** limited viewpoint/ports/time window; request owner approval for retest plan.

Use the one-minute owner summary: “We established a safe baseline, found expected web exposure to validate, and need an owner-approved HTTPS and firewall-policy review. No compromise was confirmed.”
